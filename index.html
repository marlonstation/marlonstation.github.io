Swift · SwiftUI · AppKit

MonitorMac

I wanted to check temperature and memory without interrupting what I was doing. I built a native app with live readings in the menu bar and a floating panel accessible by a global shortcut.

The standard build shows system thermal state, RAM usage, and ten minutes of history. The demo shows the experimental build, which also displays CPU and GPU temperatures.

Swift · SwiftUI · AppKit · Core Audio

VolumeMac

I built a compact mixer to switch audio outputs and adjust microphone gain from the macOS menu bar. An optional floating shortcut opens the controls beside its icon.

The prototype also lets you adjust volume and choose an output for each app without changing the Mac’s default output. These per-app controls are experimental.

Source and build instructions
